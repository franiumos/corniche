# Corniche

A test build of a driving game for the iPhone: a Ferrari 458 on a coast road above the sea, drawn with WebGPU and real ray-traced reflections and shadows (computed on the GPU, since WebGPU has no hardware ray tracing).

This build is check-in 1. The car drives itself while the page measures how much ray tracing the phone can carry, then shows the numbers.

Open it in Safari on iOS 26 or later. For full screen, use Share › Add to Home Screen and start it from the icon.
